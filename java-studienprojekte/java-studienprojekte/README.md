# Java Coursework

Java assignments from my Bachelor in Computer Science of Technical Systems (HAW Hamburg), second semester programming course. Code comments are in German.

| Project | Topic | Concepts |
|---|---|---|
| [Lab 1](praktikum-1) | Custom I/O streams | `InputStream`/`OutputStreamWriter` subclasses, custom exception, Base64 encoding, JUnit |
| [Lab 2](praktikum-2-generic-map) | Own generic map | Generics, implementing `java.util.Map`, `Comparable`, input validation with Guava, JUnit |
| [Lab 4](praktikum-4-javafx-mvc) | Desktop app | JavaFX, MVC pattern, file loading, live search and filtering |

## Build
- Lab 1: Ant projects (NetBeans), JUnit 4 needed for the tests
- Lab 2 and Lab 4: Maven (`mvn test`, and `mvn clean javafx:run` for Lab 4)
